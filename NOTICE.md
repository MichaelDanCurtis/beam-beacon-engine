# NOTICE

`beam-beacon-engine` is the shared engine repo for two Ailuxis terminal
products:

- **Beam** — the open-source agentic terminal at <https://www.beam.Ailuxis.com>
- **Beacon** — the proprietary enterprise terminal

Both products consume this engine. The engine is licensed permissively
(MIT OR Apache-2.0) so Beam can stay free / open-source while Beacon can
ship as a closed-source commercial product.

## Provenance

Every line in this repository is hand-written by the Ailuxis team. **Nothing
in this repo is extracted, copied, or derived from upstream Warp**
(<https://github.com/warpdotdev/warp>) or from the Beam fork. When a
feature exists in Beam and we need to unify it with Beacon, the rule is
*rewrite cleanly here*, not copy across.

This intentional separation keeps the dual-license grant of this repo
unambiguous and avoids any tension with upstream Warp's dual MIT/AGPL
offer. See the Beam repository's own `NOTICE.md` for Warp attribution
specific to that fork.
